# Usar os temporizadores

## Alternar modo

Selecione uma das três abas no topo:

- **Relógio** mostra hora e data locais em português.
- **Cronômetro** mede o tempo transcorrido.
- **Pomodoro** alterna foco e pausas automaticamente.

## Relógio

O Relógio atualiza hora e data automaticamente. Ele usa o fuso local e formato de 24 horas.

## Cronômetro

1. Selecione **Cronômetro**.
2. Pressione o botão central para iniciar ou pausar.
3. Pressione `↺` para zerar o tempo e remover voltas.
4. Pressione `⚑` para registrar uma volta.

O estado permanece enquanto você alterna de modo. A apresentação mostra horas, minutos e segundos.

## Pomodoro

1. Selecione **Pomodoro**.
2. Pressione `▶` para iniciar o foco de 25 minutos.
3. Pressione `Ⅱ` para pausar ou retomar.
4. Pressione `↺` para reiniciar a etapa atual.
5. Aguarde a pausa curta de 5 minutos; após quatro focos, a pausa terá 15 minutos.

Cada transição tenta enviar notificação do sistema e reproduzir som. Se o sistema não oferecer o recurso, o aplicativo usa o fallback visual.

## Manter a janela visível

Marque **Sempre no topo** no rodapé. O estado vale para todos os modos enquanto o aplicativo estiver aberto.
